# 문서 변환기 · PDF↔이미지

PDF를 장별 이미지로 풀거나, 사진 여러 장을 PDF 1개로 묶는 웹앱입니다.
계약서·신분증 사본처럼 밖으로 나가면 안 되는 문서를 다루기 때문에,
**파일은 어디로도 업로드되지 않고 이 기기 브라우저 안에서만 변환됩니다.**

- 앱: https://dollgap.github.io/pdf-image/

## 무엇을 하나요

**PDF → 이미지**
- PDF 한 개를 페이지마다 PNG 또는 JPG로 변환
- 화질 두 단계 (일반 1.5x / 고화질 2.5x)
- 페이지별 `저장`·`공유`, 그리고 `전체 ZIP 저장`

**이미지 → PDF**
- 사진 여러 장을 한 번에 골라 PDF 1개로 (나중에 추가 선택 가능)
- 사진마다 순서 위/아래 이동, 90° 회전, 삭제
- 페이지 비율 `A4 맞춤` 또는 `사진 원본 크기`
- 완성된 PDF는 `저장` 또는 `공유`

## 개인정보

- 서버·CDN 호출이 없습니다. PDF 엔진(pdf.js)을 포함한 모든 스크립트와 글꼴 데이터가
  저장소 안에 들어 있어 인터넷이 끊겨도 그대로 동작합니다.
- 변환 결과는 기기의 다운로드 폴더로 바로 저장되며, 앱은 아무것도 보관하지 않습니다.
- 홈 화면에 추가하면 일반 앱처럼 전체 화면으로 열립니다(오프라인 동작).

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면과 변환 로직 전체 (PDF 렌더링, 순수 JS PDF 작성기, ZIP 작성기) |
| `vendor/` | pdf.js 엔진 (`pdf.min.mjs`, 워커), CJK CMap, 표준 글꼴 |
| `manifest.json` / `sw.js` / `sw-files.json` | PWA 설치 정보와 오프라인 캐시 목록 |
| `tools/make_icons.py` | 앱 아이콘 생성 스크립트 |

## 기술 메모

- PDF → 이미지: pdf.js로 각 페이지를 캔버스에 렌더링한 뒤 PNG/JPEG로 인코딩합니다.
- 이미지 → PDF: 사진을 EXIF 방향에 맞춰 캔버스에 그리고 JPEG으로 인코딩해,
  PDF 1.4 파일을 직접 조립합니다(`/DCTDecode` 이미지 XObject, 원본 바이트 그대로).
- ZIP: Store(무압축) 방식 ZIP을 순수 JS로 작성합니다. 이미 압축된 PNG/JPEG라 재압축 이득이 없습니다.
